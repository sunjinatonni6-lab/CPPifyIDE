# Cppify — TinyBasic C++ / WebAssembly compiler engine

Cppify is a browser IDE for a deliberately small custom programming language. Its lexer, parser, expression evaluator, variable store and execution engine are implemented in **C++** and compiled to **WebAssembly** with Emscripten. JavaScript is only the browser UI/host bridge; it does not interpret TinyBasic source code.

This is **not** a compiler for arbitrary standard C++ programs.

## Language specification

| Feature | Syntax |
| --- | --- |
| Variables | `let age = 25;` |
| Output | `print age;` |
| User input | `input name;` |
| Assignment | `age = 26;` |
| Arithmetic | `+`, `-`, `*`, `/`, `%` |
| Power | `2 ^ 3` or `2 ** 3` |
| Increment / decrement | `age++;` / `age--;` |
| Expressions | `print (5 + 3) * 2;` |
| Unary operators | `-10`, `+5` |
| Comments | `// comment` or `# comment` |
| Optional semicolons | `let x = 10` |

String literals and `+` string concatenation are also supported for convenient output. Statements are line-oriented: put one statement on each line. `input` uses the browser's native prompt dialog.

## Build the WebAssembly engine

1. Install and activate the [Emscripten SDK](https://emscripten.org/docs/getting_started/downloads.html).
2. Open a terminal in this project directory.
3. Run:

   ```bash
   ./build-wasm.sh
   ```

The build generates `tinybasic.js` and `tinybasic.wasm` next to `index.html`. These are generated build artifacts and are not committed in this source archive.

## Run locally

After building, serve this directory over HTTP (for example, with VS Code Live Server or `python -m http.server 8000`) and open `http://localhost:8000`. Do not open the page with `file://`; browsers generally block WebAssembly fetches from local files.

## Deploy to Vercel

Build the two WebAssembly assets before deployment, then commit/upload the project including `tinybasic.js` and `tinybasic.wasm`. Configure Vercel with **Framework Preset: Other**, **Build Command: empty**, and **Output Directory: `.`.** The included `vercel.json` keeps the site as a static deployment; no compiler API or runtime server is used.

## Architecture

- `tinybasic.cpp` — complete C++ lexer, parser, evaluator and runtime.
- `build-wasm.sh` — reproducible Emscripten build command.
- `app.js` — editor controls, terminal rendering, input prompt and WebAssembly bridge only.
- `tinybasic.js` / `tinybasic.wasm` — generated by the build script.

No Piston, Judge0, JDoodle, or other hosted compiler service is called.
